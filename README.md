# Projeto 2P - Agricultura de Precisao na qualidade do Solo

- Nosso projeto visa resolver a falta de informações rápidas e precisas sobre as condições do solo diminuindo que pode ocasionar a perda da produtividade. O produto auxilia na tomada de decisões sobre irrigação, fertilização e cultivo, impactando na produtividade do produtor.
